Add this feed in Google Calendar

Google Calendar does not use the .ics download the same way Apple or Outlook might. Subscribe by URL instead so your calendar stays in sync when consensus updates.

  1. Open Google Calendar in a desktop web browser.
  2. On the left, next to Other calendars, click the + button.
  3. Choose From URL (sometimes labeled like “Subscribe to calendar” with a URL field).
  4. Paste the link below and confirm / add the calendar.
