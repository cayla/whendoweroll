Subscribe to calendar

Subscribe by URL (not a one-time file import) so sessions stay in sync when group consensus changes.

How to subscribe

Google Calendar

  1. Open Google Calendar on the web.
  2. Next to Other calendars, click + → From URL.
  3. Paste the feed URL above and add the calendar.

Apple Calendar

  1. On Mac: File → New Calendar Subscription. On iPhone/iPad: Calendars → Add Calendar → Add Subscription.
  2. Paste the feed URL above and subscribe.

Outlook

  1. In Outlook on the web: Add calendar → Subscribe from web.
  2. Paste the feed URL above and import.
